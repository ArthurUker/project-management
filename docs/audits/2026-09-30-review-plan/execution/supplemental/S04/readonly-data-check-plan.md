# S04 只读关系异常核查方案

## 当前状态

未连接业务数据库，未运行查询，也未报告任何存量异常数量。执行前须由数据所有者提供获准的只读副本/快照及目标 schema 版本；产品负责人书面决定脱敏和异常导出边界。

## 查询目标（只对获准只读副本执行）

1. 统计 `tasks.parent_id` 非空且父任务 `project_id <> child.project_id` 的数量；输出仅聚合数量，样例使用不可逆脱敏 ID。
2. 统计指向缺失父行的 parent 引用（如 FK 允许历史约束漂移时），与软删父行分别计数。
3. 统计 phase/task 项目不一致及 deleted phase 仍被活动 task 引用。
4. 统计 dependency 两端跨项目、自环；对任意长度环使用有限资源的只读递归查询，记录深度上限和超限数量，不将截断结果当作全量无环证明。
5. 汇总成员重复身份、deleted_at / left_at 组合异常，仅在 S01 决定业务不变量后解释。

## 安全与输出

- 以事务只读模式运行；设定 statement timeout、递归深度/行数上限；不导出正文、姓名、令牌或附件路径。
- 记录副本标识、schema/migration 状态、查询文本 SHA256、执行时间与退出状态。
- 报告聚合值及采样限制；禁止自动修复或生成可直接执行的 UPDATE/DELETE。
- 由数据所有者审查每一类异常的处置候选，再单独设计兼容性迁移、回填/隔离与回滚方案；本审计不执行。

解除条件：获准只读副本、确认目标 schema、批准数据最小化输出口径。
